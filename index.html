Quick Reference

SetA collection or group of objects.
ElementAn object or member that belongs to a set.
Finite SetA set with a countable, limited number of elements.
Infinite SetA set that continues without end.
SubsetA set whose elements all appear in another set.
Proper SubsetA subset that is not equal to the original set.
Empty Set, ∅A set containing no elements. It is a subset of every set.
∈ / ∉Means “is an element of” / “is not an element of.”
2ⁿ RuleA set with n elements has 2ⁿ total subsets.
